# 宜蘭青年資源地圖 Yilan Resource Atlas

公開資料驅動的宜蘭縣教育、文化與青年公共參與資源探索工具。整合政府開放資料與人工查核之公開資訊，以地圖與鄉鎮比較指標呈現資源分布，作為青年志工、學生與地方行動者查找資源、規劃服務前的資料盤點起點。

線上展示：https://doreen1113.github.io/yilan-resource-atlas/

## 專案定位

這不是一份「蒐集資料、丟到地圖上」的展示頁面，而是刻意做成可重現、可驗證、可持續更新的小型資料系統：

- 每一筆資料都標註來源網址與查核日期，可回頭核對。
- 座標分為「官方公布」與「待地理編碼」兩種可信度，不假裝精確。
- 明確記錄資料缺口（例如宜蘭縣開放資料平台目前連線異常、部分鄉鎮資料尚未查得），而不是用臆測填補。
- 鄉鎮比較指標只呈現「目前可查證之公開資料現況」，並在網站上明文聲明不能代表完整資源供給或服務品質。

## 目錄結構

```
yilan-resource-atlas/
├── index.html            # 網站主頁
├── css/style.css
├── js/app.js              # 讀取 data/*.json，渲染地圖、篩選、比較表
├── data/
│   ├── resources.json     # 資源主表（欄位定義見 resources.schema.md）
│   ├── townships.json     # 12 鄉鎮市人口、面積背景資料
│   └── resources.schema.md
├── scripts/
│   └── update_museums.py  # 自動重抓文化部博物館 API，見下方「資料更新機制」
└── .github/workflows/
    └── update-museums.yml # 排程執行 update_museums.py，開 PR 而非直接寫入 main
```

## 本機開發

不能直接用 `file://` 開啟（fetch 讀取本地 JSON 會被瀏覽器擋下），需用簡易 HTTP server：

```bash
python -m http.server 8765
# 開啟 http://127.0.0.1:8765/index.html
```

## 資料方法與限制

詳見網站內「方法與限制」頁，或 `data/resources.schema.md`。簡述：

1. 資料來自各機關公開網頁或開放資料 API，逐筆人工查證名稱、地址、來源與最後更新時間。
2. 無官方座標的地址以 OpenStreetMap Nominatim 概略地理編碼（多為路名或地標層級精度），標記為 `needs_geocoding`。
3. 教育資源指標點使用之偏遠地區學校分級多為 104 學年度（2015）舊資料，僅供歷史對照，非最新現況，已在網站上明確標註。
4. 鄉鎮面積資料存在版本差異（內政部 2009 年地籍資料 vs. 近期維基百科引用內政部最新公告），本專案採用後者，並在方法頁說明差異來源。

## 資料更新機制

這份資料不是一次性快照，但也沒有假裝「全自動」——依資料來源分兩種維護方式：

1. **有穩定開放 API 的類別（目前僅文化部博物館資料）**：`scripts/update_museums.py` 會重新查詢 API、比對宜蘭縣清單，只更動這個來源管理的資料列，其餘人工建立的資料不受影響。`.github/workflows/update-museums.yml` 每週一自動執行這支腳本；若資料有變動，會開一個 Pull Request 而不是直接寫進 main，讓人有機會複核（尤其是新據點的鄉鎮欄位，API 本身沒有提供，需要人工補上）再合併。
2. **沒有 API、需人工查證的類別**（圖書館地址、數位機會中心營運狀態、志工平台、教育資源指標點等）：無法自動重抓，改在網站上用查核天數提示新鮮度——超過 30 天顯示「待複查」，超過 90 天顯示「資料可能已過期」。這個機制不會讓資料變新，但至少讓使用者知道哪些資料該重新人工確認。

手動執行更新腳本：

```bash
python scripts/update_museums.py
```
