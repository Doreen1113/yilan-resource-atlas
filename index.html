      資料處理方式

      1. 從各機關公開網頁或開放資料 API 逐筆查證名稱、地址、座標與最後更新時間。
      2. 統一欄位格式（鄉鎮市名稱、分類代碼），移除重複或已停止服務之據點。
      3. 無官方座標者標記為「待地理編碼」，以地址概略定位，不視為精確座標。
      4. 人口與面積數據取自官方統計資料，用於計算「每萬人資源數」之背景指標。
      5. 有穩定開放 API 的類別（目前為文化部博物館資料）由排程程式每週自動重新查詢並提出更新；沒有 API、需人工查證的類別（圖書館地址、數位機會中心營運狀態、志工平台等）無法自動更新，改以「查核天數」提醒使用者資料可能過期。

      每筆資料超過 30 天未查核會標示「待複查」，超過 90 天標示「資料可能已過期」；這個天數是查核新鮮度的提醒門檻，不代表資料在門檻內就保證正確。

      這份資料不能代表什麼

      本平台呈現的是「目前可查證之公開資料」，不代表各鄉鎮的完整資源供給、服務品質或實際需求。資源數量少，可能反映當地確實資源不足，也可能只是尚未開放或尚未數位化建檔。使用者不應以此直接推論「政府忽略某鄉鎮」，而應作為進一步實地查證與資源盤點的起點。

      「每萬人資源數」在人口極少的鄉鎮（例如大同鄉、南澳鄉不到7千人）容易被少數幾筆資料（尤其是教育資源指標點）撐高，數字偏高不代表資源真的充裕，解讀時請同時參考「資源總數」與「涵蓋類型數」。
